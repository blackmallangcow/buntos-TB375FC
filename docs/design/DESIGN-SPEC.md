# buntOS 디자인 스펙 v0.1

- 상태: 초안 (Draft)
- 작성일: 2026-10-28
- 개정 이력
  - v0.1 (2026-10-28): 처음 정의. 공통 토큰(`theme/tokens.css`), 메뉴 막대와 메뉴 막대 항목, 제어 센터, 모든 앱, Dock, 알림, 시스템 설정 창의 규칙과 변경 체크리스트
- 범위: buntOS가 직접 만든 화면(네이티브 UI). 지금은 `bunt-shell`(메뉴 막대, Dock, 모든 앱, 알림, 제어 센터, 배경화면)과 `bunt-settings`(시스템 설정)이다. GNOME 앱처럼 가져온 앱은 이 스펙을 따르지 않는다.
- 관련 문서: [설계안 5장 UI/UX](ARCHITECTURE.md#5-uiux-제2-목표)
- 목적
  - 네이티브 화면들이 같은 경험을 주게 한다.
  - UI를 고칠 때 빠뜨리는 부분(어둡게, 영어 문구, 키보드 동작, 문서)을 줄인다.

## 1. 기준과 원칙

**기준.** 사용 경험의 기준은 Apple이다.
- 모양과 동작은 macOS 26(Tahoe, Liquid Glass)과 macOS 27을 따른다.
- 판단이 갈리면 [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/)를 따른다.
- macOS에 같은 것이 있으면 그 배치, 이름, 순서를 먼저 따른다. 다르게 할 때는 이유를 이 문서에 적는다.

**원칙.**
1. **내용이 먼저다.** 시스템 화면(메뉴 막대, Dock, 메뉴)은 유리 재질로 뒤를 비추고 색을 아낀다. 색은 상태(켬, 연결됨)와 주요 동작에만 쓴다(HIG Color: "Apply color sparingly").
2. **사람이 정한다.** 메뉴 막대에 무엇을 보일지는 사용자가 시스템 설정에서 정한다(HIG Menu bar extras: "Let people — not your app — decide").
3. **없는 것은 알맞게 뺀다.** 장치나 서비스가 없으면 메뉴 막대 항목은 숨긴다. 제어 센터와 시스템 설정에서는 꺼진 모양과 까닭("사용할 수 없음", "Wi-Fi 장치가 없습니다")을 보인다. 메뉴 항목은 숨기지 않고 끈다(HIG Menu bar).
4. **숫자는 토큰에만 쓴다.** 색, 모서리, 글자 크기, 그림자는 `theme/tokens.css` 변수만 쓴다. 앱 CSS에 숫자를 직접 쓰면 다음 개편에서 빠진다.
5. **한국어가 먼저다.** 문구는 macOS 한국어판 용어를 따르고, 영어 문구를 함께 넣는다(Fluent, 12장).

## 2. 토큰 (`theme/tokens.css`)

`bunt-shell`과 `bunt-settings`는 자기 `style.css`보다 이 파일을 먼저 읽는다:

```rust
concat!(include_str!("../../theme/tokens.css"), include_str!("../data/style.css"))
```

- GTK 4.16 이상이 CSS 변수를 읽는다. 이미지의 GTK는 4.24다.
- 어둡게는 창에 붙는 `dark` 클래스가 변수 값을 바꾼다(10장).

### 2.2 재질 (유리)

| 변수 | 값(밝게) | 쓰임 |
|---|---|---|
| `--glass` | 흰색 60% | 넓은 패널: 모든 앱, Dock |
| `--glass-strong` | #f6f6f8 80% | 글이 많은 곳: 메뉴, 메뉴 막대 항목, 제어 센터, 알림 카드 |
| `--glass-fill` | 흰색 45% | 유리 위의 모듈: 제어 센터 칸, 분류 칩 |
| `--glass-highlight` | 흰색 60% | 유리 가장자리 안쪽의 밝은 선 |
| `--glass-outline` | 검정 12% | 유리 바깥의 얇은 선 (밝은 배경에서 경계) |

**흐림.** macOS의 유리처럼 bunt-comp가 셸 표면 뒤를 흐리게 한다(`comp/src/blur.rs`, `comp.toml`의 `[effects] blur`).
- 대상: 셸의 overlay·top 레이어 표면과 그 팝업(메뉴, 제어 센터, 모든 앱, Dock, 알림 배너). 메뉴 막대 자체는 흐리지 않는다.
- 흐리는 곳: 표면 알파가 0.5 이상인 곳만 흐리고, 그림자처럼 옅은 곳은 그대로 둔다. 그래서 유리 바탕의 알파는 0.5 이상, 그림자는 0.35 아래로 둔다.
- 방법: dual Kawase(1/8 축소), 채도 1.4.
- 흐림을 끄면 뒤 창의 글자가 겹쳐 보일 수 있다. 그때는 `--glass`, `--glass-strong`의 불투명도만 높인다(80~90%). 컴포넌트 CSS는 고치지 않는다.

### 2.5 움직임

| 변수 | 값 | 쓰임 |
|---|---|---|
| `--duration-fast` | 120ms | 가리킴, 누름 |
| `--duration` | 200ms | 패널이 나타남, 메뉴 막대 배경 바뀜 |

## 4. 메뉴 막대

- **높이와 글자.** 높이 28px. 글자는 13px, 흰색, 그림자 0 1px 2px 35%.
- **배경.** 평소에는 투명하다. 앞에 있는 창이 최대화나 전체 화면이면 검정(#000)이 된다(200ms 전환).
- **왼쪽.** 로고 메뉴(이 시스템에 관하여, 시스템 설정…, 다시 시작…, 시스템 종료…), 앞에 있는 앱의 이름(굵게)과 메뉴.
- **앱 메뉴.** 앱이 D-Bus로 내보낸 동작(GAction)과 창 조작으로 만든다. 순서는 HIG를 따른다: 앱 이름, 파일, 편집, 보기, 창, 도움말.
- **오른쪽.** 순서는 macOS를 따른다. 앱 항목이 왼쪽 끝이다.

  ```
  [앱 항목들] [방해 금지(켠 동안)] [입력 소스] [Bluetooth] [사운드] [배터리] [Wi-Fi] [제어 센터] [날짜·시간]
  ```

- **단추.** 가로 여백 9px, 모서리 `--radius-sm`. 가리키거나 열면 흰색 22% 바탕.
- **아이콘.** 16px 기호(symbolic) 아이콘이다. 메뉴 막대에서는 흰색과 그림자로 그린다.
- **날짜·시간.** 누르면 알림 센터가 열린다. 형식은 시스템 설정의 12/24시간제를 따른다.

## 5. 메뉴와 메뉴 막대 항목

### 5.1 메뉴 (로고 메뉴, 앱 메뉴)

- **판.** 유리(`--glass-strong`), 모서리 `--radius-lg`, 안쪽 여백 5px, `--shadow-menu`, 바깥선 `--glass-outline`.
- **항목.** 높이 22px, 가로 여백 10px.
- **가리킨 항목.** 강조색 바탕에 흰 글씨(macOS와 같다).
- **열 때.** 내용은 띄우기 전에 채운다. 포인터가 메뉴 안에서 움직이기 전에는 어떤 줄도 칠하지 않는다. Esc로 닫는다.
- **나머지.** 꺼진 항목은 `--label-tertiary`, 단축키는 `--label-secondary`. 구분선은 위아래 4px, 좌우 10px 들여 쓴다.
- **글자.** 메뉴 막대의 흰 글씨와 그림자를 물려받지 않게 메뉴 안에서 다시 정한다.

### 5.2 메뉴 막대 항목 (menu bar extra)

모양과 행동은 [HIG: The menu bar › Menu bar extras](https://developer.apple.com/design/human-interface-guidelines/the-menu-bar#Menu-bar-extras)를 따른다.

**아이콘.**
- 한 색의 기호 아이콘(16px)으로 상태를 보인다. 글자가 필요하면 테두리 안의 글자로 쓴다(입력 소스의 "A", "한").
- 앱 항목도 같은 이름의 `-symbolic` 아이콘이 테마에 있으면 그것을 쓴다.

**누르면.** 메뉴(유리 판)가 열린다. 메뉴의 줄 종류는 다음과 같다.

| 줄 | 모양 | 예 |
|---|---|---|
| 제목 | 굵은 글씨, 오른쪽에 스위치나 값 | "Wi-Fi [스위치]", "배터리 80%" |
| 묶음 머리글 | 11px, 600, `--label-secondary` | 알고 있는 네트워크, 전원 모드 |
| 설명 | 12px, `--label-secondary` | 전원: 전원 어댑터, 남은 시간 2시간 5분 |
| 항목 | 26px 동그라미 아이콘(켜짐·연결됨이면 강조색), 이름, 설명, 오른쪽 아이콘 | Wi-Fi 네트워크, Bluetooth 기기 |
| 고르기 | 앞에 체크 표시 | 입력 소스, 전원 모드, 출력 장치 |
| 동작 | 글자만, 끝에 "…" | Wi-Fi 설정…, 배터리 설정… |
| 막대 | 굵은 막대(22px, 채운 쪽 흰색), 앞에 아이콘(누르면 음소거) | 음량 |

**행동.**
- 항목, 고르기, 동작을 누르면 메뉴를 닫는다. 스위치와 막대는 닫지 않는다.
- 가리킨 줄은 `--hover`로 칠하되, 포인터가 메뉴 안에서 실제로 움직인 뒤에만 칠한다(`pointer-moved`).
- 동작 줄은 메뉴 맨 아래에 두고 시스템 설정의 해당 페이지를 연다(`bunt-settings <페이지>`).

**보이기.** 시스템 설정의 메뉴 막대 페이지가 정하고(GSettings `org.buntos.shell`), 장치나 서비스가 없으면 숨긴다.

| 항목 | 키 | 기본 | 숨기는 때 |
|---|---|---|---|
| Wi-Fi(네트워크) | `show-wifi` | 켬 | NetworkManager 없음 |
| Bluetooth | `show-bluetooth` | 끔 (macOS와 같다. 제어 센터에 있다) | 어댑터 없음 |
| 사운드 | `show-sound` | 켬 | 출력 장치 없음 |
| 배터리(전원) | `show-battery` | 켬 | 없음. 배터리가 없으면 전원 어댑터 아이콘 |
| 배터리 남은 양(%) | `show-battery-percentage` | 끔 | |
| 입력 소스 | `show-input-source` | 켬 | fcitx5 없음, 입력 소스가 하나 |
| 앱 항목 | `show-status-items` | 켬 | |
| 방해 금지 | (없음) | | 방해 금지가 꺼져 있음 |

**항목별 메뉴.**
- **배터리.** 배터리가 있으면 10% 단위 배터리 아이콘(충전 중 표시)을, 없으면 전원 어댑터 아이콘을 보인다. 메뉴에는 상태와 전원 모드(저전력 모드, 자동, 고성능; power-profiles-daemon)가 있고, 고르면 바로 적용한다.
- **Wi-Fi.** 제목 스위치, 연결된 네트워크(강조), 알고 있는 네트워크, 기타 네트워크(최대 8개, 잠금·신호 아이콘)가 나온다. 저장된 네트워크와 암호 없는 네트워크는 바로 연결한다. 암호가 필요한 새 네트워크는 시스템 설정의 Wi-Fi 페이지에서 암호를 받는다. Wi-Fi 장치가 없으면 유선 상태와 "네트워크 설정…"만 보인다.
- **입력 소스.** 지금 그룹의 입력 소스를 고르기 줄로 보인다(ABC, 2벌식). 그 아래 전환 단축키 안내(Ctrl+Space, 한/영)와 "키보드 설정…".

**앱 항목(StatusNotifierItem).**
- 셸이 `org.kde.StatusNotifierWatcher`와 호스트를 맡는다.
- 메뉴(com.canonical.dbusmenu)가 있으면 5.1의 메뉴로 보이고, 없으면 누를 때 앱에 Activate를 보낸다.
- 상태가 Passive인 항목은 숨긴다. fcitx5 항목은 입력 소스 항목이 대신하므로 보이지 않는다.

## 6. 제어 센터

메뉴 막대의 제어 센터 아이콘(스위치 두 개)을 누르면 유리 판(`--radius-xl`, 안쪽 여백 10px) 위에 모듈이 4칸 격자로 놓인다.

```
┌──────────────┬──────────────┐
│ ● Wi-Fi      │ ● 방해 금지  │
│   집 Wi-Fi   │   끔         │
│ ● Bluetooth  ├──────┬───────┤
│   켬         │  ●   │  ●    │
```

| 모듈 | 크기 | 내용 |
|---|---|---|
| 연결 | 2×2 | Wi-Fi(유선만 있으면 이더넷), Bluetooth. 동그라미 단추로 켜고 끈다 |
| 방해 금지 | 2×1 | 켜면 알림 배너를 띄우지 않는다. 알림은 알림 센터에 쌓인다 (`org.gnome.desktop.notifications show-banners`) |
| 다크 모드 | 1×1 | `org.gnome.desktop.interface color-scheme` |
| 저전력 모드 | 1×1 | power-profiles-daemon `power-saver` ↔ `balanced` |
| 디스플레이 | 4×1 | 밝기 막대 (`/sys/class/backlight`, logind `SetBrightness`) |
| 사운드 | 4×1 | 음량 막대 (WirePlumber) |

**모양.**
- 모듈: `--glass-fill` 바탕, `--radius-lg`, 안쪽 여백 10px.
- 동그라미 단추: 30px. 켜면 강조색에 흰 아이콘, 끄면 `--control-bg`.

## 7. 모든 앱

macOS 26의 응용 프로그램 창을 따른다.

**여닫기.**
- Dock의 앱 단추를 누르면 화면 가운데에 유리 패널이 나타난다. 모든 앱은 화면 전체를 덮는 투명한 overlay 창이다.
- 패널 바깥을 누르거나 Esc를 누르면 닫힌다. 검색어가 있으면 Esc는 먼저 검색어를 지운다.

**패널.** 860×620px, `--glass`, `--radius-2xl`, `--shadow-panel`. 화면이 작으면 가운데에 두어도 메뉴 막대와 Dock에 닿지 않게 줄인다(1280×800에서 860×560).

**구성 (위에서 아래로).**
1. 앱 아이콘(24px)과 검색 칸(17px, 테두리 없음). 패널 어디서든 글자를 치면 검색 칸으로 간다. Enter는 보이는 첫 앱을 연다.
2. 분류 칩: 유틸리티, 개발자 도구, 생산성, 창의력, 인터넷, 엔터테인먼트, 게임, 교육 및 참고, 기타.
   - .desktop의 Categories에서 정한다.
   - 앱이 있는 분류만 보인다. 하나만 고르고, 다시 누르면 푼다.
3. 최근에 쓴 앱 한 줄(7개). 거르는 중에는 숨긴다. Dock과 모든 앱에서 실행한 것을 센다(`org.buntos.shell recent-apps`).
4. 모든 앱: 7열 격자, 64px 아이콘, 이름 두 줄. 가리키면 `--hover`, 누르면 `--pressed`.

**열기.** 이미 실행 중인 앱은 새로 띄우지 않고 창을 앞으로 가져온다(Dock도 같다).

## 8. Dock, 알림, 배경화면

**Dock.**
- 판: 유리(`--glass` 계열), `--radius-xl`.
- 아이콘: 48px. 실행 중이면 아래에 4px 점.
- Dock에 없는 실행 중인 앱은 구분선 뒤에 놓는다.
- 전체 화면에서는 숨는다.

**알림.**
- 배너는 오른쪽 위(메뉴 막대 아래 8px)에 5초 보인다. 방해 금지 중에는 띄우지 않는다.
- 알림 센터는 날짜·시간을 눌러 연다. 판 없이 카드만 보이고(카드는 `--glass-strong`, 18px), 달력 위젯이 함께 나온다.

**배경화면.**
- 셸이 background 층에 화면을 채우게 그린다(남는 부분은 자른다).
- 기본 그림 5장(`/usr/share/backgrounds/buntos/`)은 `tools/wallpapers/generate.py`가 만든다.
- 다크 모드에서는 `picture-uri-dark`를 쓴다.

**입력기 후보 창 (한자 변환, 입력 소스 표시기).**
- fcitx5 테마 `buntos`와 `buntos-dark`(`image/mkosi.extra/usr/share/fcitx5/themes/`): Pretendard, 세로 목록, 강조색 파랑. 밝게·어둡게를 따른다.
- 글자 커서 바로 아래에 뜨고, 아래에 자리가 없으면 위로 옮긴다(bunt-comp).

## 9. 시스템 설정 창

macOS 26 시스템 설정을 따른다. 코드는 `settings/src/window.rs`(틀), `widgets.rs`(공통 부품), `data/style.css`.

**창.**
- 900×640(최소 너비 720). 제목 표시줄이 없다.
- 사이드바 맨 위가 창 손잡이고, 본문 맨 위 오른쪽에 창 단추가 있다.
- 처음 열면 Wi-Fi 페이지다.

**사이드바**(`--sidebar-bg`, 오른쪽 구분선).
- 위에서부터 검색 칸, 사용자(실명 또는 사용자 이름, "로컬 계정"), 페이지 목록이다.
- 검색은 페이지 이름과 낱말로 거르고, Enter는 첫 결과를 연다.
- 페이지 목록은 묶음 사이를 12px 띄운다. 항목은 28px, 모서리 8px다. 8px은 토큰 사이 값이라 지금은 CSS에 숫자로 있다. 다음 개편 때 토큰으로 옮긴다.
- 항목 앞에 색 배지(그라데이션 둥근 사각형에 흰 기호)를 둔다.
- 고른 항목은 `--selection` 바탕에 흰 글씨다.

**본문 머리.** 알약 모양의 뒤로·앞으로 단추(방문 기록), 페이지 제목(굵게).

**본문.**
- 페이지 머리 행: 큰 배지, 제목, 한 줄 설명, 필요하면 스위치.
- 묶음 머리글: 굵게, 13px. 그 아래 묶음 상자(`--group-bg`, `--radius-md`)가 온다.
- 묶음 안의 행은 위아래 8px, 좌우 12px이고, 행 사이에 `--separator` 선을 둔다.
- 행의 오른쪽 부속: 스위치(38×22, 켜면 강조색), 드롭다운, 단추, 체크 표시, 상태 점(초록 연결됨, 주황 진행 중, 회색 꺼짐), ⋯ 메뉴, 원 안의 − 단추(지우기).
- 묶음 아래 설명: 11px, `--label-secondary`.

**작은 대화(시트).**
- 작은 모달 창이다: 배지, 제목, 설명, 내용, 아래쪽에 취소·확인.
- Esc로 닫는다. 확인 단추는 강조색이다.
- 예: Wi-Fi 암호, 세부사항, 입력 소스 추가.

**알림.** 작업 결과는 본문 아래쪽에 잠깐 뜨는 알림으로 알린다.

**없을 때.** 장치나 서비스가 없으면 페이지 가운데에 큰 배지와 까닭을 보인다. 예: Wi-Fi 장치 없음, 컴포지터 API 없음.

**단축키.** Ctrl+F 검색, Alt+←/→ 뒤로·앞으로, Ctrl+W 닫기.

**페이지 이름.** 다른 프로그램은 `bunt-settings <이름>`으로 페이지를 연다. 이미 떠 있으면 페이지만 바뀐다. 이 이름은 바꾸지 않는다.

| 이름 | 페이지 | 배지 색 | 쓰는 것 |
|---|---|---|---|
| `wifi` | Wi-Fi | 파랑 | NetworkManager |
| `bluetooth` | Bluetooth | 파랑 | BlueZ |
| `network` | 네트워크 | 파랑 | NetworkManager |
| `battery` | 배터리 | 초록 | UPower, power-profiles-daemon, `org.buntos.shell` |
| `appearance` | 화면 모드 | 그래파이트 | `org.gnome.desktop.interface` |
| `menu-bar` | 메뉴 막대 | 그래파이트 | `org.buntos.shell` |
| `wallpaper` | 배경화면 | 하늘 | `org.gnome.desktop.background` |
| `display` | 디스플레이 | 파랑 | 컴포지터 API(`org.buntos.Compositor1`), logind 밝기 |
| `keyboard` | 키보드 | 회색 | 컴포지터 API, fcitx5, `org.buntos.shell` |
| `language` | 언어 | 남색 | 사용자 환경(`~/.config/environment.d`) |
| `datetime` | 날짜와 시간 | 회색 | timedated |
| `about` | 정보 | 회색 | hostnamed |

## 10. 다크 모드

- 시스템 설정의 화면 모드나 제어 센터에서 바꾼다(`org.gnome.desktop.interface color-scheme`).
- 셸과 설정 창은 창에 `dark` 클래스를 붙여 토큰 값을 바꾸고, GTK 기본 위젯은 prefer-dark를 쓴다.
- 메뉴 막대 글자는 모드와 상관없이 흰색이다(macOS와 같다).
- 새 컴포넌트는 밝게와 어둡게를 모두 화면으로 확인한다.

## 11. 상호작용과 접근성

**누름과 포커스.**
- 누를 수 있는 것은 가리키면 `--hover`, 누르면 `--pressed`.
- 키보드 포커스는 `:focus-visible`에서 강조색 2px 테두리로 보인다.

**키보드.**
- Esc는 열린 패널·메뉴를 닫는다.
- Enter는 기본 동작이다(모든 앱: 첫 결과).
- Ctrl+Space와 한/영은 입력 소스를 바꾼다.

**스위치와 막대.**
- 스위치: 시스템 설정 창 38×22, 메뉴와 제어 센터 30×18. macOS의 보통·작은 크기다. 켜면 강조색, 손잡이는 흰색이다.
- 막대: 시스템 설정은 가는 홈에 강조색 채움(눈금은 고를 값이 정해진 때만), 제어 센터와 메뉴는 22px 굵은 막대(채운 쪽 흰색)다.

**누를 영역.** 포인터 모드에서 최소 22px(메뉴 항목)이다. 터치 모드(설계안 5.1)에서는 44px로 키운다(아직 없음).

**대비.** 유리 위 글자는 `--label`(85%) 이상으로 쓴다. 보조 글자(`--label-secondary`)는 정보가 아닌 설명에만 쓴다.

## 12. 문구

- 문자열은 Fluent(`i18n/ko`, `i18n/en`)에 넣는다. 두 언어의 메시지 ID가 같은지 테스트가 검사한다.
- 용어는 macOS 한국어판을 따른다.

  | 영어 | 한국어 |
  |---|---|
  | Control Center | 제어 센터 |
  | Do Not Disturb | 방해 금지 |
  | Low Power Mode | 저전력 모드 |
  | Known Networks / Other Networks | 알고 있는 네트워크 / 기타 네트워크 |
  | Input Source, ABC, 2-Set Korean | 입력 소스, ABC, 2벌식 |
  | Menu Bar | 메뉴 막대 |

- 더 많은 화면을 여는 동작은 "…"로 끝낸다(Wi-Fi 설정…).
- 상태는 짧은 명사형으로 쓴다(켬, 끔, 연결됨, 완전히 충전됨).

## 13. 아이콘

- **기호 아이콘.** Adwaita 기호 아이콘(adwaita-icon-theme 51)을 먼저 쓴다.
- **직접 만든 아이콘.** 없는 것은 `shell/data/icons/`에 16×16 기호 SVG(채움만, 검정)로 만들고 이름에 `org.buntos.` 접두사를 단다. 지금 있는 것: Logo, Apps, ControlCenter, Focus(방해 금지), Appearance(다크 모드), LowPower.
- **앱 아이콘.** 컬러다(Dock 48px, 모든 앱 64px, 알림 32px).

## 14. UI를 바꿀 때 체크리스트

1. 필요한 색·크기를 `theme/tokens.css`에서 찾는다. 없으면 토큰을 먼저 더하고 2장 표를 고친다.
2. 밝게·어둡게 두 모드 모두 확인한다.
3. 문구를 한국어와 영어로 넣는다(`cargo test`가 메시지 ID를 맞춰 본다).
4. 장치·서비스가 없을 때의 모양(숨김, 사용할 수 없음)을 정한다.
5. 키보드로 열고 닫고 고를 수 있는지 본다(Esc, Enter, 화살표).
6. 빌드 VM에서 이미지를 띄워 화면을 캡처해 확인한다(`tools/image/vmctl.sh`, [개발 환경](../dev/environment.md)).
7. 이 문서의 해당 절과 개정 이력을 고친다.
